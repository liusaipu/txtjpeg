# TxtJPEG-C 构建与使用指南

本文档汇总 `txtjpeg-c` 项目的目录结构、编译方法、使用方式以及 Visual Studio 2013 导入步骤。

---

## 二、使用方法

编译完成后得到可执行文件 `txtjpeg`（Linux/macOS）或 `txtjpeg.exe`（Windows）。

### 2.1 压缩

```bash
txtjpeg compress input.txt output.tj --quality 85
```

### 2.2 解压

```bash
txtjpeg decompress output.tj output_approx.txt
```

### 2.3 显式指定二维形状

```bash
txtjpeg compress input.txt output.tj --quality 85 --shape 10000x5789
```

> `--shape` 的格式为 `行数x列数`，程序会自动把宽高向上对齐到 8 的倍数。

### 2.4 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `compress` / `decompress` | 必填 | 子命令 |
| `<input>` | 必填 | 输入文件路径 |
| `<output>` | 必填 | 输出文件路径 |
| `--quality N` | 85 | JPEG 质量，1–100 |
| `--shape HxW` | 自动 | 显式指定二维图像形状 |

## 三、编译方法

### 3.1 Linux / macOS / MSYS2（Makefile）

依赖：`gcc` / `clang`、`make`、`libjpeg` 或 `libjpeg-turbo`

```bash
cd txtjpeg-c
make
```

生成可执行文件 `txtjpeg`。

清理：

```bash
make clean
```

### 3.2 CMake（跨平台）

依赖：`cmake`、`libjpeg` 或 `libjpeg-turbo`

```bash
cd txtjpeg-c
mkdir build && cd build
cmake ..
make
# Windows 上：cmake --build . --config Release
```

CMake 会自动查找系统安装的 JPEG 库。

### 3.3 Windows MSYS2 + MinGW-w64

在 MSYS2 UCRT64 终端中：

```bash
pacman -S mingw-w64-ucrt-x86_64-gcc
pacman -S mingw-w64-ucrt-x86_64-make
pacman -S mingw-w64-ucrt-x86_64-libjpeg-turbo

cd txtjpeg-c
mingw32-make
```

得到原生 Windows 可执行文件 `txtjpeg.exe`。

### 3.4 Windows Visual Studio 2013

见下一节详细步骤。

## 四、Visual Studio 2013 导入方法

### 4.1 准备 libjpeg-turbo

VS2013 较老，现代 vcpkg 通常要求 VS2015+，因此建议手动准备 libjpeg-turbo：

#### 方案 A：下载官方预编译包

1. 访问 libjpeg-turbo 官方 Release 页面。
2. 下载适合 VS2013 的版本，例如 `libjpeg-turbo-2.0.6-vc64.exe`。
3. 安装后得到：
   - `include/jpeglib.h`
   - `lib/jpeg.lib`
   - `bin/jpeg62.dll`

#### 方案 B：用 VS2013 从源码编译

```bat
git clone https://github.com/libjpeg-turbo/libjpeg-turbo.git
cd libjpeg-turbo
git checkout 2.0.6

mkdir build && cd build
cmake -G "Visual Studio 12 2013 Win64" -DCMAKE_BUILD_TYPE=Release -DWITH_TURBOJPEG=OFF ..
cmake --build . --config Release
```

编译后在 `build/Release` 中得到 `jpeg.lib` 和 `jpeg62.dll`。

### 4.2 创建 VS2013 项目

1. 打开 Visual Studio 2013。
2. `文件 → 新建 → 项目 → Visual C++ → Win32 → Win32 控制台应用程序`。
3. 项目名称填 `txtjpeg`，勾选“空项目”。
4. 在解决方案资源管理器中右键项目 → `添加 → 现有项`，选择 `txtjpeg-c` 目录下的所有 `.c` 文件：
   - `main.c`
   - `parser.c`
   - `format.c`
   - `shape.c`
   - `normalize.c`
   - `jpeg_codec.c`
   - `container.c`
   - `compress.c`
   - `decompress.c`

### 4.3 配置头文件路径

右键项目 → `属性`：

- `配置属性 → C/C++ → 常规 → 附加包含目录`：
  - 添加 libjpeg-turbo 的 `include` 目录，例如：
    ```
    C:\libjpeg-turbo\include
    ```

### 4.4 配置库文件路径

- `配置属性 → 链接器 → 常规 → 附加库目录`：
  - 添加 libjpeg-turbo 的 `lib` 或 `Release` 目录，例如：
    ```
    C:\libjpeg-turbo\lib
    ```

- `配置属性 → 链接器 → 输入 → 附加依赖项`：
  - 添加：
    ```
    jpeg.lib
    ```

### 4.5 统一运行库

libjpeg-turbo 的 `jpeg.lib` 必须与 exe 使用相同的 C 运行时库：

- `配置属性 → C/C++ → 代码生成 → 运行库`：
  - 如果 libjpeg-turbo 是用 `/MD` 编译的，选择 **多线程 DLL (/MD）**。
  - 如果 libjpeg-turbo 是用 `/MT` 编译的，选择 **多线程 (/MT）**。

> 运行时库不匹配会导致链接错误（如 `LNK2038`）。

### 4.6 添加预处理宏

- `配置属性 → C/C++ → 预处理器 → 预处理器定义`：
  - 添加：
    ```
    _CRT_SECURE_NO_WARNINGS
    ```

### 4.7 编译与运行

1. 选择 `Release` 和 `x64` 平台。
2. `生成 → 生成解决方案`。
3. 得到 `txtjpeg.exe`。
4. 把 `jpeg62.dll` 复制到 `txtjpeg.exe` 所在目录。
5. 打开命令提示符，运行：

```bat
txtjpeg.exe compress input.txt output.tj --quality 85
txtjpeg.exe decompress output.tj output_approx.txt
```

## 六、与 Python 版互操作

`.tj` 容器格式与 Python 版完全一致，可互相读写：

```bash
# C 压缩，Python 解压
txtjpeg compress test_data_raw.txt test_c.tj --quality 85
python ../txtjpeg.py decompress test_c.tj test_py_decomp.txt

# Python 压缩，C 解压
python ../txtjpeg.py compress test_data_raw.txt test_py.tj --quality 85
txtjpeg decompress test_py.tj test_c_decomp.txt
```

## 七、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 找不到 `jpeglib.h` | JPEG 头文件路径未配置 | 检查附加包含目录 |
| 链接错误 `LNK2019` | 未链接 `jpeg.lib` | 检查附加依赖项 |
| `LNK2038` 运行时库不匹配 | /MD 与 /MT 混用 | 统一运行库设置 |
| 运行提示缺少 DLL | DLL 不在 PATH 或同目录 | 把 `jpeg62.dll` 放到 exe 同目录 |
| 解压文件变大或乱码 | 未按二进制打开 | 代码中已用 `"rb"` / `"wb"` |
| 输出与 Python 版不一致 | 容器版本或格式推断不同 | 检查 `TJPEG_VERSION` 和 `fmt_str` |
